What "Demo Mode" actually is

No smoke and mirrors — here's exactly what happens when you click "Try Live Demo."

What it is

Demo Mode signs you in as a wallet address we own and control, pre-seeded with agents already compiled and committed on X Layer testnet. It lets you see the full product — compiler, Signal Monitor, live agent cards, real transaction hashes — without installing a browser extension or holding testnet OKB.

What's real

  • Every transaction hash shown is a real X Layer testnet transaction — click through to the explorer and verify it yourself
  • The compiler runs the same LLM pipeline as the connected-wallet flow
  • Agent configs and their onchain hashes are genuine, not mocked data

What's different from Connect Wallet

In Demo Mode, when you "commit" an agent onchain, the transaction is signed by our demo signer (funded with testnet OKB only) rather than popping up your own wallet extension. This is the only difference — it exists purely so you don't need to set up a wallet just to evaluate the product. Switch to Connect Wallet at any point to run the identical flow signing with your own MetaMask or OKX Wallet.
